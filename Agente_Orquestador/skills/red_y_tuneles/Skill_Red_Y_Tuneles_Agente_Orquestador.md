# Skill: Red y Túneles Remotos (Multi-Red)
**Agente:** Agente Orquestador (Luffy)  
**Propósito:** Proporcionar conectividad integral para dispositivos móviles tanto en la misma red Wi-Fi como en redes móviles remotas (4G LTE / Datos).

## Capacidades:
1. **Detección automática de IP Local Wi-Fi:** Identifica la ruta directa en LAN (`192.168.0.x`).
2. **Generación de Túneles SSH Seguros (localhost.run):** Túneles inversos HTTPS resilientes a censuras de ISP en Venezuela y restricciones geográficas.
3. **Presentación bimodal:** Provee automáticamente enlaces para la misma red Wi-Fi y para redes externas.
