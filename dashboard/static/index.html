Conectar Tripulación Remota

Instrucciones para reportar telemetría desde clientes o servidores

Cualquier equipo de agentes que instales en un servidor o máquina remota puede reportar su estado, salud de los agentes y fallos en tiempo real enviando un ping periódico por HTTP POST a este endpoint:

POST http://<TU-IP>:8000/api/telemetria/reportar

Ejemplo de código en Python (insertar en el bucle del agente remoto):

import requests, time

payload = {
    "id": "cliente-01",
    "nombre": "Equipo Alpha • Cliente X",
    "tipo": "Cloud VPS",
    "ip": "198.51.100.24",
    "version": "v1.0",
    "estado": "activa", # 'activa', 'espera', 'error', 'desconectada'
    "agentes": {
        "luffy": "activo", "zoro": "activo", "sanji": "espera", "robin": "activo", "nami": "activo"
    },
    "tarea_actual": "Generación de informes de ventas nocturnos",
    "error_critico": None, # o string con mensaje de error si falla
    "tokens": 45000,
    "cpu": 22.5,
    "ram": 58.0
}

# Enviar latido cada 10 segundos
requests.post("http://<TU-IP>:8000/api/telemetria/reportar", json=payload)
